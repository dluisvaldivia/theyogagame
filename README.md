# THE YOGA GAME 🧘

A kids' yoga game built with React 19 + Vite + TypeScript + Framer Motion.

## How it works

1. Press **START**
2. A pose card appears with the pose name, difficulty stars, and an image
3. Press **LET'S GO!** to begin the countdown (Get in position → 3, 2, 1, GO!)
4. Hold the pose for up to 20 seconds - the counter counts up with a color gradient (white → yellow → orange → red)
5. A celebration emoji flashes when you finish, then the next pose appears
6. Complete all 5 poses to reach the final screen

## Stack

- **React 19** + **TypeScript 6** + **Vite 8**
- **Framer Motion 12** for all transitions and animations
- CSS animations for the rainbow background

## Running locally

```bash
npm install
npm run dev
```
